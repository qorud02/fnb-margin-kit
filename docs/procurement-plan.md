# 한국어 구매계획 보고서

`fnb-procure`의 `--html` 옵션은 기존 세 파일과 같은 계산을 읽기 쉬운 한국어 HTML로 저장합니다.

```console
fnb-procure examples/procurement/ingredients.csv examples/procurement/recipes.csv examples/procurement/plan.csv --stock examples/procurement/stock.csv --html --output-dir purchase-plan
```

`purchase-plan/procurement.html`을 브라우저에서 열면 구매할 포장 수·원물량·예상 지출·사용 후 잔량을 먼저 볼 수 있습니다. 별도 표에서 가식부와 원물 필요량, 현재 원물 재고, 부족량을 구분하고 기준 판매계획을 확인합니다. 추가 구매가 없는 재료도 표시합니다.

파일에는 외부 글꼴·스크립트·네트워크 연결이 없습니다. 파일 하나를 전달해 오프라인으로 열 수 있으며, 브라우저 인쇄 메뉴에서 가로 방향으로 인쇄할 수 있습니다. 모바일은 표를 가로로 스크롤합니다. 원가·재고 정보가 포함되므로 열람 권한이 있는 사람에게만 전달하세요.

수량과 금액은 소수점 4자리까지 반올림합니다. `≈` 표시는 정확한 분수에서 표시를 줄였다는 뜻입니다. 마우스를 수치에 올리면 정확한 분자·분모와 소수값을 확인할 수 있고, `procurement.json`에는 원래 정확값이 유지됩니다. HTML 표시 반올림은 포장 수 올림이나 지출 계산에 영향을 주지 않습니다. 원화 등 통화를 임의로 붙이지 않고 입력한 가격의 동일 통화 단위를 사용합니다.

유통기한·예약 재고·거래처 납기·최소 주문량·배송비는 계산에 포함하지 않습니다. 이 파일은 입력 계획의 계산 결과이며 거래처로 발송된 주문서나 실제 운영 성과가 아닙니다. 예제 CSV는 가상 데이터입니다.

옵션을 빼면 기존 JSON·Markdown·CSV 세 파일만 생성되며 기존 형식과 계산값은 유지됩니다. 옵션을 넣으면 `procurement.html`도 입력 CSV와 다른 출력 파일의 경로·하드링크 충돌 검사 대상이 됩니다. HTML 생성과 검증이 끝난 뒤 파일을 씁니다.
