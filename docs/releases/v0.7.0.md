## 한글 발주 보고서 / Offline purchase report

Generate a self-contained HTML purchase report from ingredient, recipe, sales-plan and available-stock CSV files. Open the report locally and print the purchasing plan without uploading business data.

- Whole-pack purchases, opening stock, shortages, remaining stock and VAT-exclusive spend share the existing exact calculation model.
- User-supplied names are escaped. The report contains no remote scripts, fonts or analytics.
- The new HTML output uses the same input/alias protection as the existing JSON, Markdown and CSV outputs.
- The example ZIP includes synthetic inputs, generated reports and Korean usage instructions.

### Build and verification

The JSON verification record is included with the release assets.

CodeQL Python security-extended analysis is available in the repository Actions and Security views for the corresponding source commit. These are build and analysis records for this software release.

### Run

```console
python -m pip install --no-index --no-deps fnb_margin_kit-0.7.0-py3-none-any.whl
fnb-procure inputs/ingredients.csv inputs/recipes.csv inputs/plan.csv --stock inputs/stock.csv --html --output-dir my-report
```

Python 3.10 or later is required. Use one monetary unit throughout; purchase spend excludes VAT. The report is an internal planning aid, with exact quantities available in the JSON and CSV files.
